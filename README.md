# # Dark Souls J2ME (Symbian Edition)

Un demake / adaptación en 2D de estilo *Dark Souls* desarrollado puramente en **Java (J2ME)**, optimizado específicamente para dispositivos móviles clásicos con resolución **320x240** (como el **Nokia E72** y otros terminales Symbian S60v3).

El proyecto corre de forma nativa mediante archivos `.jar`, ofreciendo una experiencia de combate desafiante y estética oscura adaptada a las limitaciones técnicas de la época dorada de los móviles.

---

## 📱 Especificaciones Técnicas
* **Plataforma:** J2ME (MIDP / CLDC)
* **SO Objetivo:** Symbian S60v3 (probado y optimizado en Nokia E72)
* **Resolución:** 320x240 píxeles (Horizontal / Landscape o Vertical según tu implementación)
* **Compilación:** Directa a `.jar`

---

## 🎮 Características del Juego
* Combate cuerpo a cuerpo inspirado en la saga *Souls* (gestión de tiempos, ataques y movimiento táctico).
* Gráficos retro y sprites optimizados para pantallas pequeñas.
* Estructura ligera pensada para correr de forma fluida sin tirones en hardware clásico o emuladores (como EKA2L1).

## 🤝 ¡Se buscan colaboradores! (Cómo contribuir)
Este proyecto es **100% de código abierto**. Si eres programador Java, artista de Pixel Art, o un apasionado del desarrollo retro para Symbian, ¡toda ayuda es bienvenida para añadir más niveles, enemigos, mecánicas y pulir los gráficos!

Pasos para colaborar:
1. Haz un **Fork** de este repositorio.
2. Crea una rama para tu mejora o característica (`git checkout -b mi-nueva-caracteristica`).
3. Realiza tus cambios y haz commit (`git commit -m 'Añadida IA de enemigos / Mejora de sprites'`).
4. Sube los cambios a tu rama (`git push origin mi-nueva-caracteristica`).
5. Abre un **Pull Request** explicando qué mejoras o arreglos hiciste para revisarlo e integrarlo al juego principal.
